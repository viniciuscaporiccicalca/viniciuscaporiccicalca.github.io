Do Rascunho ao Mil (SaaS EdTech)

Sobre o Projeto

Desenvolvi integralmente a infraestrutura digital do Do Rascunho ao Mil, uma plataforma SaaS de educação focada na preparação de estudantes para o ENEM. O projeto envolveu a criação de uma arquitetura escalável e segura, focada em uma experiência de usuário (UX) fluida e intuitiva.

Stack Tecnológica: Implementação utilizando Next.js 16, Supabase (Auth, SSR e Database) e TypeScript.

Destaques e Funcionalidades:

  • Gestão de Assinaturas: Integração completa com Stripe API para processamento de pagamentos recorrentes e checkout seguro.
  • Dashboards de Dados: Desenvolvimento de gráficos de linha dinâmicos utilizando Recharts para monitoramento de métricas de desempenho dos alunos.
  • Segurança e Rotas: Implementação de lógica de proteção de rotas via Middleware/Proxy para gerenciar acessos distintos entre alunos, professores e administradores.
  • Interface Interativa: Criação de landing page e dashboards com animações de entrada e transições suaves utilizando Framer Motion.
